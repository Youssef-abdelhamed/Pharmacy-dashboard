# Pharmacy-dashboard
Pharmacy Analytics Dashboard 📊💊
Overview
An interactive, comprehensive dashboard for monitoring and analyzing sales performance, profitability, and operational metrics of a multi-branch pharmacy chain. Built with Power BI using realistic simulated data to provide actionable business insights for data-driven decision making.

Key Features ✨
📈 Multi-Page Analytics
Overview: Executive KPIs and business summary

Region: Performance analysis across 4 regions (Cairo, Alexandria, Delta, Gaza)

Sales: Transaction details and profitability metrics

Medicines: Product-level insights by generic name and batch

Customers: Customer segmentation and behavior analysis

📊 Core Metrics Tracked
Financial: Net Profit (108.56K), Total Paid (357.92K), Average Profit Margin (38%)

Operational: Bills (1906), Stores (5), Sales Representatives (7)

Product: Medicines (20), Manufacturers (17)

Demographic: Average Customer Age (39.56)

🔍 Advanced Interactivity
Dynamic Filtering by:

Date (Month, Year)

Region

Store

Customer Type (Retail/Wholesale)

Product/Manufacturer

Cross-Filtering: Click on any visual to filter the entire dashboard

Real-time Updates: Dashboard responds immediately to filter changes

Dashboard Structure 🏗️
1. Overview Page

Key KPIs: Stores, Regions, Average Age, Average Net Profit, Average Profit Margin

Regional Profit Analysis: Paid vs. Net Profit comparison per region

Store Performance: Detailed metrics per store (3001, 3003, 3005, 3007)

2. Region & Sales Pages

Net Profit Summary: 108.56K total

Sales Performance: Analysis per sales representative with time filters

Customer Type Insights: Percentage distribution across regions

3. Medicines Page

Product Portfolio: Medicine and manufacturer counts

Top Medicines: Net Profit and Total Sales for key drugs

Batch Analysis: Profitability by batch number with temporal tracking

4. Customers Page
Customer Segmentation: Analysis by customer type across regions

Purchase Behavior: Patterns for retail and wholesale customers

Technical Implementation ⚙️
Tools & Technologies
Development Tool: Microsoft Power BI Desktop

Data Processing: Power Query Editor (Data transformation & cleaning)

Data Source: Realistic simulated datasets (Not included in repository)

Dashboard Type: Fully interactive with advanced filtering

Visualizations: Bar Charts, Donut Charts, Tables, KPI Cards, Slicers

Power BI Features Utilized
✅ Power Query for data loading and transformation

✅ DAX for advanced measure calculations

✅ Interactive Slicers for dynamic filtering

✅ Bookmarks for navigation states

✅ Tooltips for detailed insights

✅ Sync Slicers for cross-page consistency

How to Use 🚀
Basic Navigation
Switch Pages: Use page tabs (Overview, Region, Sales, Medicines, Customers)

Interact with Visuals:

Hover over any chart for detailed tooltips

Click on bars/chart elements to cross-filter the dashboard

Advanced Filtering
Use the filter pane to control:

Time Range: Select specific months or years

Region: Focus on single or multiple regions

Store: Analyze specific branches

Customer Type: Compare retail vs. wholesale

Products: Drill into specific medications

Data Refresh
Current implementation uses static simulated data

Can be connected to live data sources (SQL, APIs) for automatic updates

Business Insights & Value 💼
Key Findings
Regional Performance: Cairo leads with 41.9% of orders and highest profit contribution

Optimal Margins: Overall 38% profit margin with regional variations (31%-39%)

Store-Level Analysis: Store 3001 shows highest average net profit per transaction

Product Strategy: Medications like Cipro and Azithromycin drive significant revenue

Customer Mix: Balanced portfolio between retail and wholesale customers

Supported Business Decisions
Inventory distribution optimization across branches

Identification of high-margin products for promotion

Sales team performance evaluation and incentive planning

Regional expansion strategy based on profitability
